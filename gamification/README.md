# Gamification

Этап 6: выполнение задачи одной транзакцией и список своей истории. Повтор и два одновременных запроса дают одно начисление. Баланс равен сумме строк истории.

Процесс читает настройки только из окружения. При старте открывает пул к `gamification_app` и проверяет связь. Если базы нет, пишет «database is unavailable» и завершается. Адрес базы и секрет в это сообщение не попадают. `/health/ready` по-прежнему 503: отдельная проверка готовности ещё не подключена.

## Библиотеки

Их четыре, каждая закрывает то, чего нет в стандартной библиотеке.

- `golang.org/x/crypto/bcrypt` — хеш пароля. Стоимость 12. Соль уже внутри хеша.
- `github.com/golang-jwt/jwt/v5` — короткий пропуск. Принимается только HS256.
- `github.com/jackc/pgx/v5/stdlib` — драйвер Postgres для `database/sql`.
- `github.com/oapi-codegen/runtime` — типы контракта. Сам контракт собирает oapi-codegen v2.5.0.

Миграции применяет [goose](https://github.com/pressly/goose) v3.24.3. В модуль приложения goose не входит.

## Запуск

Имена настроек — в `.env.example`. Файл с живыми значениями в репозиторий не класть.

```sh
export DATABASE_DSN='postgres://localhost:5432/gamification_app?sslmode=disable'
export JWT_SECRET='замените-на-строку-длиннее-31-символа'
go run ./cmd/api
```

Без `DATABASE_DSN` или с `JWT_SECRET` короче 32 символов процесс завершается и пишет имя настройки. Папка, из которой запущена команда, на настройки не влияет.

Короткий пропуск живёт `JWT_ACCESS_TTL` (по умолчанию 15 минут). Издатель и аудитория — оба из `JWT_ISSUER`. Длинный пропуск — случайная строка на `JWT_REFRESH_TTL` (по умолчанию 720 часов). В базе хранится только её sha256.

Регистрация и вход: не больше 10 запросов в минуту с одного адреса, дальше 429. Кривой JSON лимит не тратит.

## Миграции

Учебную базу `gamification` этой командой не указывать.

```sh
export DATABASE_DSN='postgres://localhost:5432/gamification_app?sslmode=disable'
go run github.com/pressly/goose/v3/cmd/goose@v3.24.3 -dir migrations postgres "$DATABASE_DSN" up
```

Вниз на один шаг: та же команда с `down`. Вторая миграция снимает только таблицу длинных пропусков.

## Контракт

```sh
make generate
```

Команда читает `api/openapi.yaml` и перезаписывает `internal/transport/http/apigen/server.gen.go`. Этот файл руками не менять.

Кривой JSON и кривые поля — 400. Нет пропуска или подпись не сходится — 401. Неизвестный путь и чужая или отсутствующая задача — 404. Чужой метод — 405. Повтор почты, смена награды у выполненной и удаление выполненной — 409. Повторное выполнение — 200 без второй награды. Частый вход — 429. `/health/live` отвечает 200 и базу не спрашивает.
